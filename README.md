# Anime Hub

Учебное приложение на HTML, CSS, Vanilla JavaScript, Firebase Authentication и Firestore.

## Возможности

- Каталог в реальном времени, поиск по названию и описанию, фильтры и сортировка, страницы по 10 карточек.
- Регистрация, вход, выход, восстановление пароля.
- Страница аниме, добавление и удаление избранного, история просмотров.
- Профиль с избранным, историей без повторов и собственными отзывами.
- Создание, редактирование и удаление отзывов. Оценка сообщества учитывает последний отзыв каждого пользователя и отображается отдельно от рейтинга каталога.
- Админка: создание, изменение и удаление аниме, модерация отзывов, изменение ролей других пользователей.
- Firestore Rules проверяют владельца, роли и входные значения; пользователь не может назначить себе admin.

## Локальный запуск

Установлен Node.js 22 или новее:

```sh
node serve.mjs
```

Открыть http://127.0.0.1:4173. Также можно использовать VS Code Live Server. Открытие через `file://` не подходит для модулей JavaScript.

## Firebase

Конфигурация Web App находится в `js/firebase.js`. Это публичная клиентская конфигурация; права доступа задаются Firestore Rules.

1. Firebase Console → Authentication → Sign-in method: включить Email/Password.
2. Firestore Database → Rules: опубликовать содержимое `firestore.rules`.
3. Authentication → Settings → Authorized domains: добавить `anurik26.github.io` для опубликованного сайта; для локальной разработки при необходимости добавить `localhost` и `127.0.0.1`.
4. Первого администратора назначить через Firebase Console: `users/{UID}`, поле `role = admin`. UID должен совпадать с Authentication. После этого других администраторов можно назначать в админке.
5. Документы `anime` должны содержать `createdAt` (Timestamp), `title`, `description`, `poster`, `year`, `status`, `episodes`, `genres`, `rating`, `ratingCount`. Аниме удобно добавлять через админку.

Локальная замена файла `firestore.rules` не меняет опубликованные правила. Изменения нужно отдельно опубликовать в Firebase Console.

## Проверки

```sh
npm test
npm install
npm run test:rules
```

Для тестов правил нужны Node.js 22+, Java 21 и интернет для загрузки Firestore Emulator. Они используют только проект `demo-anime-hub`, не подключаются к рабочим данным. GitHub Actions запускает эти проверки автоматически.

Проверка сценариев в браузере: регистрация сохраняет имя; каталог загружает следующую страницу; поиск находит записи за пределами первой страницы; избранное добавляется и удаляется; история не исчезает при пустом избранном; отзыв редактируется и меняет оценку сообщества; обычному пользователю запрещена админка; администратор может создать анонс с 0 эпизодов.

## Ограничения учебной версии

Поиск по подстроке и сортировка по рейтингу загружают весь каталог. Это подходит для небольшого учебного набора; для большого каталога нужен поисковый сервис. Обычный просмотр использует ограниченный realtime-запрос, лимит увеличивается при «Показать ещё».
История хранит отдельные просмотры, а профиль объединяет повторы при отображении. Удаление аниме не удаляет связанные отзывы, избранное и историю; отсутствующий тайтл показывает понятное сообщение. Управление пользователями означает управление ролями в Firestore; удаление учётных записей Authentication выполняется в Firebase Console.
